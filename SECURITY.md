# Security Policy

## Project status

PQVPN is in the planning stage and has no supported release. Nothing in this
repository should currently be relied on to protect production traffic or
sensitive data.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request. Instead, use GitHub's **Security** tab and select **Report a
vulnerability** if private vulnerability reporting is available for this
repository.

Include the following information when possible:

- The affected component and version or commit.
- Steps needed to reproduce the issue.
- The expected and observed behavior.
- The potential security impact.
- Any suggested mitigation or supporting material.

Please avoid accessing data that does not belong to you, disrupting services,
or publishing details before the maintainer has had a reasonable opportunity
to investigate and respond.

Supported versions and response expectations will be documented when PQVPN has
its first release.
