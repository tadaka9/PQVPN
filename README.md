# PQVPN

PQVPN is a planned free and open-source VPN project. The name stands for
**Path-Quit VPN**.

> [!IMPORTANT]
> PQVPN is in the planning stage. This repository does not currently contain a
> runnable application or a published release.

## Project goals

- Make private networking approachable and free to use.
- Provide a transparent, auditable open-source implementation.
- Keep setup and day-to-day operation simple.
- Develop secure defaults before publishing a production-ready release.

These are project goals, not claims about the current implementation.

## Status

The initial source code, supported platforms, protocol design, installation
instructions, and release schedule have not yet been published. This README
will be updated as those decisions are made.
