# PQVPN 0.0.19 David1 beta GUI

This release adds an opt-in Dark Souls mode to the Privacy Console.

- A charcoal, ember, blood-red and antique-gold visual theme is available
  from **View → Appearance → Dark Souls mode · fail closed**.
- Connection states gain distinctive language while preserving exact meaning:
  protected, relay-only, securing, stopping and failed remain separate states.
- A failed protected path reads **YOU DIED · FAIL CLOSED** only when the node
  actually reports failure; the mode never presents relay-only operation as
  VPN protection.
- The preference persists locally and can be disabled at any time.
- Linux, macOS and Windows CI render every GUI page in Souls mode in addition
  to the existing dark and light visual tests.

This is a presentation preset, not an affiliation with or endorsement by any
game publisher, and it does not change PQVPN's cryptographic claims.
