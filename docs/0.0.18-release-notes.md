# PQVPN 0.0.18 David1 beta GUI

This release makes tunnel intent explicit and validates it before runtime.

- Profiles without a `tunnel` section run as relay-only nodes and do not try
  to create a local TUN device.
- A present native PQVPN `tunnel` section remains full-tunnel by default for
  compatibility; it must define a non-empty interface name plus a numeric exit
  address and valid port. External plugins continue to use their own required
  configuration path.
- `"tunnel": {"enabled": false}` explicitly selects relay-only operation.
- `--no-tunnel` remains a runtime override for diagnostics and server roles.

As a result, `--validate-config` and normal startup now agree: an incomplete
full-tunnel profile fails validation before the UDP listener starts, while a
legacy profile containing only network settings starts without a local tunnel.
