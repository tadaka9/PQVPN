# PQVPN 0.0.16 beta

This beta repairs two user-visible regressions found during live mainnet use.

- The Linux egress bridge now retains unacknowledged server-to-client TCP
  segments and retransmits them after duplicate acknowledgements or a bounded
  timeout. A lost tunnel datagram no longer leaves large pages permanently
  half-loaded.
- StrangeNet's transcript now follows the active light or dark theme. The
  transcript widget is styled explicitly and ordinary messages no longer force
  a light foreground onto a light background.

The retransmission queue is bounded by the existing per-flow in-flight limit,
and a flow is reset after eight unsuccessful attempts instead of retaining
memory indefinitely. No connection identifiers, peer addresses, or message
contents are added to telemetry by this change.
