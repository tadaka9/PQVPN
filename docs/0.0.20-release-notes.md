# PQVPN 0.0.20 — release narrative

> **THE PATH OPENS. THE KEYS REMAIN YOURS.**

This release establishes a consistent, evidence-led publication voice for
PQVPN. Release pages now open with a clear identity, show the five native
admission gates, explain every artifact, provide a checksum-first verification
path, and close with the exact experimental boundary.

GitHub-generated changelogs are grouped into security, native experience,
networking, packaging, and operational documentation. The presentation is
deliberately cinematic; the claims remain tied to observable CI evidence.

PQVPN remains experimental and has not received an independent security audit.
The new release format does not change that boundary or imply anonymity.
