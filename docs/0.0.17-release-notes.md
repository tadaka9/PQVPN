# PQVPN 0.0.17 David1 beta GUI

This release starts the GUI-focused beta line while retaining the verified
networking corrections from 0.0.16.

- Public version: `0.0.17-10162026-David1-beta-GUI`.
- `David1` records David's direct participation in defining and testing this
  release.
- `GUI` identifies the release focus; it does not remove the CLI, TUI, node,
  Linux packages, or cross-platform artifacts from the protected build.
- The StrangeNet transcript theme fix and bounded TCP retransmission support
  introduced in 0.0.16 remain included.

PQVPN remains experimental beta software. The GUI label is not a security
certification and does not broaden the project's anonymity claims.
