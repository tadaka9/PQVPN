# PQVPN 0.7.0 David1 alpha HONESTY

> **THE PATH OPENS. THE KEYS REMAIN YOURS.**

Status: **candidate only until exact-tag CI, local physical-device launch
verification and protected publication pass**.

A green hosted build is not sufficient evidence that the Android package can
start. Before publication, an authorized physical device must pass
`tools/verify-android-on-device.sh` against the exact signed candidate APK.

HONESTY changes the public development label from beta to alpha. This is a
technical maturity classification, not a moral judgement about earlier work.
The independent audit, complete native functional qualification, production
signing, reproducible performance evidence and mobile VPN adapters are still
incomplete.

Version `0.7.0` follows the immutable historical `0.6` release line. The later
`0.0.x` tags are preserved as historical facts, but are not used as the base for
future ordering because doing so would make new packages appear older than
`0.6` to package managers and update clients.

## Changes

- Labels current packages and public surfaces as experimental alpha.
- Corrects the Android runtime/NDK pairing and respects Android safe-area
  insets so status and navigation bars do not cover the mobile interface.
- Preserves every historical tag and release without moving or rewriting it.
- Extends prerelease tooling to accept explicit alpha or beta labels while
  retaining exact-commit CI, immutable tags, checksums, provenance and the
  protected publisher.
- Publishes a dated research-status map and keeps reinforcement learning at
  research-only status; the current bounded-SGD predictor is not RL.
- Records AIGuardian as an external read-only observer. Its cryptobiosis uses
  fixed 95% memory, 98% disk or three-error triggers and has no PQVPN authority.

## Current limits

- No anonymity guarantee or independent security certification.
- No production-qualified Windows tunnel driver or signed mobile VPN.
- No faster-than-WireGuard claim without reproducible comparative benchmarks.
- No production coin, transferable value, public Asgard cloud or RL agent.
- No proof that an active sidecar, server process or UI control protects a
  route; authenticated end-to-end evidence remains required.

The candidate version is `0.7.0-10182026-David1-alpha-HONESTY`. Publication
must remain fail-closed if any exact-tag native candidate, checksum, provenance
or protected-environment gate is missing.
