# Support PQVPN

PQVPN is experimental open-source security research. The most useful support is
technical: review the design, test a verified release on hardware you control,
report reproducible results, and improve focused documentation or tests.

## Help the project become easier to discover

- [Star PQVPN on GitHub](https://github.com/tadaka9/PQVPN) if the work earned it.
- Share the [project website](https://tadaka9.github.io/PQVPN/) with people who
  can evaluate the protocol and native clients critically.
- Open a [focused issue](https://github.com/tadaka9/PQVPN/issues/new/choose) with
  the release, platform, configuration and reproduction steps. Remove secrets
  and personal data from logs first.

## Security reports

Never attach a vulnerability report to a donation or public issue. Follow the
[private reporting process](../SECURITY.md) so the maintainer can investigate it
without exposing users.
